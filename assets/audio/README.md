# Audio Assets Directory

noTube 등에서 다운로드한 고음질 MP3 파일을 이 폴더(`assets/audio/`)에 넣어주세요.

### 💡 파일명 권장 형식
* `가수명 - 곡명.mp3` (예: `성시경 - 너의 모든 순간.mp3`, `DAY6 - 한 페이지가 될 수 있게.mp3`)
* 파일명을 기준으로 유튜브 영상 제목, 설명란, 해시태그가 자동 생성됩니다.

### 🎵 동작 방식
* 폴더 내에 여러 개의 MP3가 있을 경우, 실행 시 랜덤으로 선곡되거나 셔플되어 8시간 영상으로 제작됩니다.
* 5~10분 길이의 MP3 하나만 올려두셔도 자동으로 8시간 연속 재생 영상으로 확장됩니다.
